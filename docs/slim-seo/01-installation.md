---
title: Installation
---

Installing Slim SEO is very easy. The plugin is free and hosted on WordPress.org. You can install it right from within your dashboard as follows:

1. Go to your _WordPress Dashboard > Plugins > Add New_.
2. Search for "**slim seo**".
3. Click the **Install** button to install the plugin.
4. Click the **Activate** button to activate it.

![Install Slim SEO within WordPress dashboard](https://imgur.elightup.com/4t04yf8.png)

Or you can manually download and install Slim SEO if you cannot install it with the method above:

1. Click the **Free Download** button in the header of this website to download the plugin file (`.zip`).
2. Go to your _WordPress Dashboard > Plugins > Add New_.
3. Click the **Upload** button.
4. Upload the downloaded `.zip` file.
5. Activate the plugin.

After installing, Slim SEO works automatically even without any configuration.

The plugin also adds a settings page under _Settings > SEO_ just in case you want to insert some scripts from Google Analytics or similar. See the documentation for [Header / Footer Code](/slim-seo/header-footer-code/) for details.

Now your website is auto optimized by Slim SEO. To understand what the plugin does, check out the feature list of Slim SEO on the left menu.
